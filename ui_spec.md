# Klarity — Streamlit UI Spec (`app.py`)

Single-file Streamlit app. 3 screens via `st.sidebar.radio("View", ["Therapist", "Patient", "Demo Control"])`. State lives in `st.session_state` (dict initialized once). All "AI" outputs are hardcoded strings from `agents.md`.

## Global setup

```python
st.set_page_config(page_title="Klarity", page_icon="🌱", layout="centered")
# Inject CSS once: warm cream bg (#FAF7F2), serif headings (Lora/Georgia),
# rounded cards (border-radius: 16px), generous padding (24px), soft shadow.
# Accent: #6B8E7F (sage green). Warning: #C97B5C (terracotta, NOT red).
```

`st.session_state` keys (set defaults in `Demo Control`):
- `session_4_ended` (bool) — gates Scribe takeaway candidates
- `takeaway_approved` (bool) — gates patient anchor
- `anchor_delivered` (bool) — toggles "delivered Tuesday 7am" stamp
- `pattern_alert_fired` (bool) — gates Pattern Agent card
- `brief_generated` (bool) — gates Session 5 brief

Sidebar also shows a small "Demo state" readout (5 booleans as ✓/–) so the presenter always knows what's live.

## Screen 3: Demo Control

Presenter dashboard. No warm styling here — utilitarian is fine.

**Header:** `st.title("Demo Control")` · `st.caption("Click these in order during the live walkthrough.")`

**Step buttons** (one per row, each a `st.container(border=True)` with a button + status pill):

1. **`▶ End Session 4 (trigger Scribe)`** → sets `session_4_ended=True`. Status: *"3 takeaway candidates surfaced in Therapist View."*
2. **`▶ Therapist approves anchor`** → sets `takeaway_approved=True`. Status: *"Anchor queued for Tuesday 7am delivery."* (Disabled until step 1.)
3. **`▶ Tuesday morning (deliver anchor)`** → sets `anchor_delivered=True`. Status: *"Anchor card live in Patient View."* (Disabled until step 2.)
4. **`▶ Friday — fire Pattern Alert`** → sets `pattern_alert_fired=True`. Status: *"Circling alert visible to Dr. Chen."*
5. **`▶ Monday — generate Session 5 Brief`** → sets `brief_generated=True`. Status: *"Pre-session brief live at top of Therapist View."*

**Footer row**
- `st.button("Reset demo", type="secondary")` → clears all 5 booleans.
- `st.caption("Tip: keep the Therapist tab open in one window, Patient in another. Drive everything from this tab.")`

**Live state table** at the bottom — `st.dataframe` of the 5 flags so the presenter can verify at a glance.

## Copy & tone rules for the builder

- No "AI-generated" badges. Use *"From Scribe Agent"* / *"From Brief Agent"* in small caption text.
- No percentages on the patient side. No scores. No streaks. No gamification.
- Never use the word "patient" in the patient view — use "you" or "friend."
- One emoji total in the whole app (🌱 in patient header). Resist all others.
- Buttons are verbs in plain language: `Approve & send`, not `Confirm action`.
